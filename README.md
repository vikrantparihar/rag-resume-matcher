# 🚀 AI Resume Matcher

An AI-powered Resume Analyzer built using Python and Streamlit that matches resumes with job roles and identifies missing skills.

## 🔥 Features
- Upload Resume (PDF)
- Analyze skills
- Match with job roles
- Identify missing skills

## 🛠 Tech Stack
- Python
- Streamlit
- PyMuPDF

## ▶️ How to Run

git clone https://github.com/vikrantparihar/rag-resume-matcher.git
cd rag-resume-matcher
pip install -r requirements.txt
streamlit run app.py
